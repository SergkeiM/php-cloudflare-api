# R2 Bucket Object Lock

Manage the object lock (retention) configuration for an R2 bucket.

:button-link[Cloudflare API docs]{icon="heroicons-outline:external-link" href="https://developers.cloudflare.com/api/operations/r2-get-bucket-lock-configuration" blank}

## Get

```php [php]
$response = $client->r2()->lock()->get('account_id', 'my-bucket');
```

## Update

```php [php]
$response = $client->r2()->lock()->update('account_id', 'my-bucket', [
    ['id' => 'rule-1', 'condition' => ['type' => 'Age', 'maxAgeSeconds' => 86400]],
]);
```
