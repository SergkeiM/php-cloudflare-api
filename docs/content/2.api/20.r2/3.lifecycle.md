# R2 Bucket Lifecycle

Manage the lifecycle configuration for an R2 bucket.

:button-link[Cloudflare API docs]{icon="heroicons-outline:external-link" href="https://developers.cloudflare.com/api/operations/r2-get-bucket-lifecycle-configuration" blank}

## Get

```php [php]
$response = $client->r2()->lifecycle()->get('account_id', 'my-bucket');
```

## Update

```php [php]
$response = $client->r2()->lifecycle()->update('account_id', 'my-bucket', [
    ['id' => 'rule-1', 'conditions' => ['maxAge' => 3600]],
]);
```
