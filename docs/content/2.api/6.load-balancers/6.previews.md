# Load Balancer Preview Results

Fetch the result of a previously requested monitor or pool preview. Previews are account-scoped.

:button-link[Cloudflare API docs]{icon="heroicons-outline:external-link" href="https://developers.cloudflare.com/api/operations/account-load-balancer-monitors-preview-result" blank}

## Get

```php [php]
$response = $client->loadBalancers()->previews()->get('account_id', 'preview_id');
```
