# Ruleset Rules

Add a rule to an existing ruleset.

:button-link[Cloudflare API docs]{icon="heroicons-outline:external-link" href="https://developers.cloudflare.com/api/operations/updateZoneRuleset" blank}

## Create

```php [php]
use Cloudflare\Configurations\Rules\BlockRule;

$rule = (new BlockRule(['error' => 'blocked']))->enable()->setExpression('true');

$response = $client->rulesets()->rules()->create(null, 'zone_id', 'ruleset_id', $rule);
```
