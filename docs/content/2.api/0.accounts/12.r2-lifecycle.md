# R2 Bucket Lifecycle

Manage lifecycle rules that automatically transition or expire objects in an R2 bucket.

:button-link[Cloudflare API docs]{icon="heroicons-outline:external-link" href="https://developers.cloudflare.com/api/operations/r2-get-bucket-lifecycle-configuration" blank}

## Details

Get the lifecycle configuration for a bucket.

```php [php]
$response = $client->accounts()->r2Lifecycle()->details('account_id', 'my-bucket');
```

## Update

Set the lifecycle configuration for a bucket.

```php [php]
$rules = [
    [
        'id' => 'expire-old-objects',
        'conditions' => [
            'maxAge' => 86400,
        ],
        'enabled' => true,
    ],
];

$response = $client->accounts()->r2Lifecycle()->update('account_id', 'my-bucket', $rules);
```
