# Bot Management

Manage the Bot Management configuration for a zone.

:button-link[Cloudflare API docs]{icon="heroicons-outline:external-link" href="https://developers.cloudflare.com/api/operations/zone-bot-management-get-config" blank}

## Details

Get the current Bot Management configuration for a zone.

```php [php]
$response = $client->zones()->botManagement()->details('zone_id');
```

## Update

Update the Bot Management configuration for a zone.

```php [php]
$values = [
    'fight_mode' => false,
];

$response = $client->zones()->botManagement()->update('zone_id', $values);
```
