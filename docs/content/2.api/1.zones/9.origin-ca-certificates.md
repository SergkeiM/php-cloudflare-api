# Origin CA Certificates

Issue and manage certificates issued by Cloudflare's Origin CA for securing connections between Cloudflare and your origin server.

:button-link[Cloudflare API docs]{icon="heroicons-outline:external-link" href="https://developers.cloudflare.com/api/operations/origin-ca-certificates-list-certificates" blank}

## List

List all Origin CA certificates.

```php [php]
$response = $client->zones()->originCACertificates()->list(['zone_id' => 'zone_id']);
```

## Create

Create an Origin CA certificate.

```php [php]
$response = $client->zones()
    ->originCACertificates()
    ->create('csr', ['example.com', '*.example.com']);
```

## Details

Get an Origin CA certificate.

```php [php]
$response = $client->zones()->originCACertificates()->details('certificate_id');
```

## Revoke

Revoke an Origin CA certificate.

```php [php]
$response = $client->zones()->originCACertificates()->revoke('certificate_id');
```
