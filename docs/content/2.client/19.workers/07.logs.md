## List

Get list of tails currently deployed on a Worker.

::params-table
---
params:
  - name: "accountId"
    type: "string"
    required: true
    description: "Account identifier."
  - name: "scriptName"
    type: "string"
    required: true
    description: "Name of the script, used in URLs and route configuration."
---
::

```php [php]
$response = $client->workers()->logs()->list('ACCOUNT_ID', 'SCRIPT_NAME');
```

::callout{icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/resources/workers/subresources/scripts/subresources/tail/methods/get/"}
View this operation on the Cloudflare API Reference
::

## Delete

Deletes a tail from a Worker.

::params-table
---
params:
  - name: "accountId"
    type: "string"
    required: true
    description: "Account identifier."
  - name: "scriptName"
    type: "string"
    required: true
    description: "Name of the script, used in URLs and route configuration."
  - name: "id"
    type: "string"
    required: true
    description: "Identifier for the tail."
---
::

```php [php]
$response = $client->workers()->logs()->delete('ACCOUNT_ID', 'SCRIPT_NAME', 'ID');
```
