Load balancers distribute traffic across your origin servers to reduce
response time and increase availability. A load balancer is scoped to
either an account or a zone: pass exactly one of $accountId or $zoneId.

## List

List configured load balancers.

::params-table
---
params:
  - name: "accountId"
    type: "string|null"
    required: false
    description: "Account Identifier. Provide exactly one of $accountId or $zoneId."
  - name: "zoneId"
    type: "string|null"
    required: false
    description: "Zone Identifier. Provide exactly one of $accountId or $zoneId."
---
::

```php [php]
$response = $client->loadBalancers()->list('ACCOUNT_ID', 'ZONE_ID');
```

::callout{icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/operations/account-level-load-balancers-list-load-balancers"}
View this operation on the Cloudflare API Reference
::
