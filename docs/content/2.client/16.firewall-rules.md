## List

List, search, sort, and filter a zone's firewall rules.

::params-table
---
params:
  - name: "zoneId"
    type: "string"
    required: true
    description: "Zone Identifier."
  - name: "params"
    type: "array"
    required: false
    description: "Query Parameters."
    default: "[]"
---
::

```php [php]
$response = $client->firewallRules()->list('ZONE_ID', []);
```

## Create

Create one or more firewall rules.

::params-table
---
params:
  - name: "zoneId"
    type: "string"
    required: true
    description: "Zone Identifier."
  - name: "rules"
    type: "array"
    required: true
    description: "Array of firewall rule definitions, each referencing a filter by id (`filter: {id}`) or by inline expression (`filter: {expression}`), e.g. `[['action' => 'block', 'filter' => ['expression' => 'ip.src eq 127.0.0.1']]]`."
---
::

```php [php]
$response = $client->firewallRules()->create('ZONE_ID', []);
```

::callout{icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/operations/firewall-rules-create-firewall-rules"}
View this operation on the Cloudflare API Reference
::

## Update Priority

---
