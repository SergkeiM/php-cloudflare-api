## Settings

Returns a list of settings (and their details) that Page Rules can apply to matching requests.

::params-table
---
params:
  - name: "zoneId"
    type: "string"
    required: true
    description: "Zone Identifier."
---
::

```php [php]
$response = $client->pageRules()->settings('ZONE_ID');
```

## List

params:
