## Export

Returns a URL where the SQL contents of your D1 can be downloaded. Note: this process may take some time for larger DBs, during which your D1 will be unavailable to serve queries. To avoid blocking your DB unnecessarily, an in-progress export must be continually polled or will automatically cancel.

::params-table
---
params:
  - name: "accountId"
    type: "string"
    required: true
    description: "Account Identifier."
  - name: "databaseId"
    type: "string"
    required: true
    description: "Database Identifier."
  - name: "currentBookmark"
    type: "string|null"
    required: false
    description: "To poll an in-progress export, provide the current bookmark (returned by your first polling response)"
  - name: "noData"
    type: "bool"
    required: false
    description: "Export only the table definitions, not their contents"
    default: "false"
  - name: "noSchema"
    type: "bool"
    required: false
    description: "Export only each table's contents, not its definition"
    default: "false"
  - name: "tables"
    type: "array"
    required: false
    default: "[]"
---
::

```php [php]
$response = $client->d1()->export('ACCOUNT_ID', 'DATABASE_ID', 'CURRENT_BOOKMARK', true, true, []);
```

::callout{icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/operations/cloudflare-d1-export-database"}
View this operation on the Cloudflare API Reference
::

## Import

Generates a temporary URL for uploading an SQL file to, then instructing the D1 to import it and polling it for status updates. Imports block the D1 for their duration.

::params-table
---
params:
  - name: "accountId"
    type: "string"
    required: true
    description: "Account Identifier."
  - name: "databaseId"
    type: "string"
    required: true
    description: "Database Identifier."
  - name: "action"
    type: "string"
    required: false
    description: "- `init`: Indicates you have a new SQL file to upload.
- `ingest`: Indicates you've finished uploading to tell the D1 to start consuming it
- `poll`: Indicates you've finished uploading to tell the D1 to start consuming it"
    default: "'init'"
  - name: "etag"
    type: "string|null"
    required: false
    description: "Required when action is `init` or `ingest`. An md5 hash of the file you're uploading. Used to check if it already exists, and validate its contents before ingesting."
  - name: "filename"
    type: "string|null"
    required: false
    description: "The filename you have successfully uploaded."
  - name: "currentBookmark"
    type: "string|null"
    required: false
    description: "This identifies the currently-running import, checking its status."
---
::

```php [php]
$response = $client->d1()->import('ACCOUNT_ID', 'DATABASE_ID', 'ACTION', 'ETAG', 'FILENAME', 'CURRENT_BOOKMARK');
```

::callout{icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/operations/cloudflare-d1-import-database"}
View this operation on the Cloudflare API Reference
::
