## List

List members of an organization.

::params-table
---
params:
  - name: "organizationId"
    type: "string"
    required: true
    description: "Organization identifier."
  - name: "params"
    type: "array"
    required: false
    description: "Array containing the necessary params, e.g. status, user.email."
    default: "[]"
---
::

```php [php]
$response = $client->organizations()->members()->list('ORGANIZATION_ID', []);
```

::callout{icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/operations/Members_list"}
View this operation on the Cloudflare API Reference
::
