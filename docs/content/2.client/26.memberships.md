## List

List memberships of accounts the user can access.

::params-table
---
params:
  - name: "params"
    type: "array"
    required: false
    description: "Array containing the necessary params."
    default: "[]"
---
::

```php [php]
$response = $client->memberships()->list([]);
```

View this operation on the Cloudflare API Reference
::

## Update

Accept or reject this account invitation.

::params-table
---
params:
  - name: "membershipId"
    type: "string"
    required: true
    description: "Membership identifier tag."
  - name: "status"
    type: "string"
    required: true
    description: "Status of this membership, e.g. accepted, rejected."
---
::

```php [php]
$response = $client->memberships()->update('MEMBERSHIP_ID', 'STATUS');
```
