## Roll

Roll the Account Owned API token secret.

::params-table
---
params:
  - name: "accountId"
    type: "string"
    required: true
    description: "Account identifier."
  - name: "tokenId"
    type: "string"
    required: true
    description: "Token identifier."
---
::

```php [php]
$response = $client->accounts()->tokens()->value()->roll('ACCOUNT_ID', 'TOKEN_ID');
```
