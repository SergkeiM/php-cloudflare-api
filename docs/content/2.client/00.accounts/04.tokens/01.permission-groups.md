## List

Find all available permission groups for Account Owned API Tokens.

::params-table
---
params:
  - name: "accountId"
    type: "string"
    required: true
    description: "Account identifier."
  - name: "params"
    type: "array"
    required: false
    description: "Array containing the necessary params, e.g. name, scope."
    default: "[]"
---
::

```php [php]
$response = $client->accounts()->tokens()->permissionGroups()->list('ACCOUNT_ID', []);
```
