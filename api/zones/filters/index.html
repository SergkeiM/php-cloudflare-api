Filters

Filters are reusable rule-matching expressions used by Firewall Rules, Rate Limiting, and other zone security products.

Cloudflare API docs

List

List all filters for a zone.

php
$response = $client->zones()->filters()->list('zone_id');

Details

Get a single filter.

php
$response = $client->zones()->filters()->details('zone_id', 'filter_id');

Create

Create one or more filters for a zone.

php
$values = [
    [
        'expression' => 'ip.src eq 127.0.0.1',
    ],
];

$response = $client->zones()->filters()->create('zone_id', $values);

Update

Update an existing filter for a zone.

php
$values = [
    'expression' => 'ip.src eq 127.0.0.1',
    'paused' => true,
];

$response = $client->zones()->filters()->update('zone_id', 'filter_id', $values);

Delete

Delete a filter for a zone.

php
$response = $client->zones()->filters()->delete('zone_id', 'filter_id');
