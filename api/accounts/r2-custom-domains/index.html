R2 Bucket Custom Domains

Manage custom domains connected to an R2 bucket.

Cloudflare API docs

List

List custom domains for a bucket.

php
$response = $client->accounts()->r2CustomDomains()->list('account_id', 'my-bucket');

Create

Add a custom domain to a bucket.

php
$values = [
    'domain' => 'assets.example.com',
    'zoneId' => 'zone_id',
    'enabled' => true,
];

$response = $client->accounts()->r2CustomDomains()->create('account_id', 'my-bucket', $values);

Details

Get an existing custom domain for a bucket.

php
$response = $client->accounts()->r2CustomDomains()->details('account_id', 'my-bucket', 'assets.example.com');

Update

Update an existing custom domain for a bucket.

php
$values = [
    'enabled' => false,
];

$response = $client->accounts()->r2CustomDomains()->update('account_id', 'my-bucket', 'assets.example.com', $values);

Delete

Remove a custom domain from a bucket.

php
$response = $client->accounts()->r2CustomDomains()->delete('account_id', 'my-bucket', 'assets.example.com');
