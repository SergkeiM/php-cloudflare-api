Load Balancer Pools

Manage groups of origins that load balancers distribute traffic across.

Cloudflare API docs

List

List configured load balancer pools for an account.

php
$response = $client->accounts()->loadBalancerPools()->list('account_id');

Create

Create a new load balancer pool for an account.

php
$values = [
    'name' => 'primary-pool',
    'origins' => [
        [
            'name' => 'origin-1',
            'address' => '192.0.2.1',
        ],
    ],
];

$response = $client->accounts()->loadBalancerPools()->create('account_id', $values);

Details

Get a single configured load balancer pool for an account.

php
$response = $client->accounts()->loadBalancerPools()->details('account_id', 'pool_id');

Update

Update an existing load balancer pool for an account.

php
$values = [
    'name' => 'primary-pool',
    'origins' => [
        [
            'name' => 'origin-1',
            'address' => '192.0.2.1',
        ],
    ],
    'enabled' => false,
];

$response = $client->accounts()->loadBalancerPools()->update('account_id', 'pool_id', $values);

Delete

Delete a load balancer pool for an account.

php
$response = $client->accounts()->loadBalancerPools()->delete('account_id', 'pool_id');

Health

Fetch the latest pool health status for a single pool.

php
$response = $client->accounts()->loadBalancerPools()->health('account_id', 'pool_id');

Preview

Preview pool health using the specified monitor and show the effective response.

php
$values = [
    'monitor' => 'monitor_id',
];

$response = $client->accounts()->loadBalancerPools()->preview('account_id', 'pool_id', $values);
