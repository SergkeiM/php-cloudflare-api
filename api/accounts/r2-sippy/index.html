R2 Bucket Sippy

Manage Sippy, incremental migration of objects from another cloud provider into an R2 bucket on read.

Cloudflare API docs

Details

Get the Sippy configuration for a bucket.

php
$response = $client->accounts()->r2Sippy()->details('account_id', 'my-bucket');

Update (Enable)

Enable Sippy for a bucket.

php
$values = [
    'source' => [
        'provider' => 'aws',
        'bucket' => 'source-bucket',
    ],
    'destination' => [
        'provider' => 'r2',
    ],
];

$response = $client->accounts()->r2Sippy()->update('account_id', 'my-bucket', $values);

Delete (Disable)

Disable Sippy for a bucket.

php
$response = $client->accounts()->r2Sippy()->delete('account_id', 'my-bucket');
