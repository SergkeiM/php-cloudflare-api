## Bookmark

Get a Time Travel bookmark for a D1 database.

Without a timestamp you get the current bookmark; with one, the nearest
bookmark at or before it. Feed either into `restore()`.

<params-table :params="[{"name":"accountId","type":"string","required":true,"description":"Account Identifier."},{"name":"databaseId","type":"string","required":true,"description":"Database Identifier."},{"name":"timestamp","type":"string|null","required":false,"description":"ISO 8601 timestamp to find the nearest bookmark at or before. Omit for the current bookmark."}]">



</params-table>

```php [php]
$response = $client->d1()->bookmark('ACCOUNT_ID', 'DATABASE_ID', 'TIMESTAMP');
```

<callout icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/d1/reference/time-travel/">

View this operation on the Cloudflare API Reference

</callout>

## Restore

Restore a D1 database to a previous point in time.

Give it exactly one of a bookmark or a timestamp — a bookmark from
`bookmark()` names an exact point, a timestamp asks D1 to find the
nearest one.

```php
$bookmark = $client->d1()->bookmark('ACCOUNT_ID', 'DATABASE_ID')->json('result.bookmark');

$client->d1()->restore('ACCOUNT_ID', 'DATABASE_ID', bookmark: $bookmark);
```

<params-table :params="[{"name":"accountId","type":"string","required":true,"description":"Account Identifier."},{"name":"databaseId","type":"string","required":true,"description":"Database Identifier."},{"name":"bookmark","type":"string|null","required":false,"description":"Bookmark to restore to. Required if `$timestamp` is not given."},{"name":"timestamp","type":"string|null","required":false,"description":"ISO 8601 timestamp to restore to. Required if `$bookmark` is not given."}]">



</params-table>

```php [php]
$response = $client->d1()->restore('ACCOUNT_ID', 'DATABASE_ID', 'BOOKMARK', 'TIMESTAMP');
```

<callout icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/d1/reference/time-travel/">

View this operation on the Cloudflare API Reference

</callout>

## Export

Returns a URL where the SQL contents of your D1 can be downloaded. Note: this process may take some time for larger DBs, during which your D1 will be unavailable to serve queries. To avoid blocking your DB unnecessarily, an in-progress export must be continually polled or will automatically cancel.

<params-table :params="[{"name":"accountId","type":"string","required":true,"description":"Account Identifier."},{"name":"databaseId","type":"string","required":true,"description":"Database Identifier."},{"name":"currentBookmark","type":"string|null","required":false,"description":"To poll an in-progress export, provide the current bookmark (returned by your first polling response)"},{"name":"noData","type":"bool","required":false,"description":"Export only the table definitions, not their contents","default":"false"},{"name":"noSchema","type":"bool","required":false,"description":"Export only each table's contents, not its definition","default":"false"},{"name":"tables","type":"array","required":false,"description":"Filter the export to just one or more tables. Passing an empty array is the same as not passing anything and means: export all tables.","default":"[]"}]">



</params-table>

```php [php]
$response = $client->d1()->export('ACCOUNT_ID', 'DATABASE_ID', 'CURRENT_BOOKMARK', true, true, []);
```

<callout icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/resources/d1/subresources/database/methods/export/">

View this operation on the Cloudflare API Reference

</callout>

## Import

Generates a temporary URL for uploading an SQL file to, then instructing the D1 to import it and polling it for status updates. Imports block the D1 for their duration.

<params-table :params="[{"name":"accountId","type":"string","required":true,"description":"Account Identifier."},{"name":"databaseId","type":"string","required":true,"description":"Database Identifier."},{"name":"action","type":"string","required":false,"description":"- `init`: Indicates you have a new SQL file to upload. - `ingest`: Indicates you've finished uploading to tell the D1 to start consuming it - `poll`: Indicates you've finished uploading to tell the D1 to start consuming it","default":"'init'"},{"name":"etag","type":"string|null","required":false,"description":"Required when action is `init` or `ingest`. An md5 hash of the file you're uploading. Used to check if it already exists, and validate its contents before ingesting."},{"name":"filename","type":"string|null","required":false,"description":"The filename you have successfully uploaded."},{"name":"currentBookmark","type":"string|null","required":false,"description":"This identifies the currently-running import, checking its status."}]">



</params-table>

```php [php]
$response = $client->d1()->import('ACCOUNT_ID', 'DATABASE_ID', 'ACTION', 'ETAG', 'FILENAME', 'CURRENT_BOOKMARK');
```

<callout icon="i-simple-icons-cloudflare" to="https://developers.cloudflare.com/api/resources/d1/subresources/database/methods/import/">

View this operation on the Cloudflare API Reference

</callout>
